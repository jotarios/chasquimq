The fastest open-source message broker for Redis.

ChasquiMQ is a Rust-native job queue built on Redis Streams. MessagePack on the wire, pipelined acks, and tokio under the hood — drop-in for your Queue / Worker / Job shape, without the per-job round trips.

quickstart.rs 
use chasquimq::{Queue, Worker, Job};
use serde::{Deserialize, Serialize};

// Payloads are MessagePack on the wire — no JSON on the hot path.
#[derive(Serialize, Deserialize)]
struct SendEmail { to: String, subject: String }

#[tokio::main]
async fn main() -> anyhow::Result<()> {
    let queue = Queue::connect("redis://127.0.0.1:6379", "emails").await?;

    queue.add("send", SendEmail {
        to: "jorge@chasquimq.dev".into(),
        subject: "shipped 1.0".into(),
    }).await?;

    Worker::new("emails")
        .concurrency(100)
        .run(|job: Job<SendEmail>| async move {
            deliver(&job.data).await
        })
        .await
}

Inline: spin a worker with cargo run --release -p chasquimq-cli -- worker emails, then watch the live tail with chasqui tail emails.
