Quickstart tab proposals

Three redesigns of the Pick your language tab strip on the ChasquiMQ landing page. Same tokens, same anti-patterns avoided. Each shown above the same code-preview block so you can read the affordance in context.

Current (for comparison)

Plain text strip with bold-active

What's there today. Reads as a label row. No visual signal that the words are switchable.

use chasquimq::{Producer, Consumer};
// requires Rust 1.85+
let id = producer.add(EmailJob { to: "ada@example.com".into() }).await?;

Proposal A — Segmented control (recommended)

Linear / Tailwind / Apple-system feel

Single bordered bar, three equal segments, the active segment lifts onto the page surface with a subtle shadow. Unmistakably a switcher at a glance, even with no icons. Icons add a tiny brand cue without going full-color.

use chasquimq::{Producer, Consumer};
// requires Rust 1.85+
let id = producer.add(EmailJob { to: "ada@example.com".into() }).await?;
Why this one. Strongest "I am a switcher" signal of the three with the least visual noise. The frame around the whole control reads as a control. Sub-millisecond render, AA contrast on both themes, monochrome-friendly, doesn't drag in anyone's brand colors as decoration. Same affordance Linear, Tailwind, Vercel, GitHub use.

Proposal B — Underline tabs with monochrome icons

Closest to current, just legible

Standard tab pattern: hover gives a surface fill, active gets the accent underline. Adds a small monochrome glyph next to each label. Lowest-risk change, but the affordance still leans on the underline alone.

use chasquimq::{Producer, Consumer};
// requires Rust 1.85+
let id = producer.add(EmailJob { to: "ada@example.com".into() }).await?;
Use this if you want minimal visual change from current. Cheapest CSS diff, but the icons + accent underline + hover-surface together carry the affordance load. Still less obvious than a frame.

Proposal C — Language cards with brand-tinted edge

Bold, brand-aware, slightly more SaaS

Three discrete cards, one per language, with the official brand color appearing only on the left edge of the active card. Largest target. Most attention-grabbing; closest to crossing into "marketing landing" territory.

use chasquimq::{Producer, Consumer};
// requires Rust 1.85+
let id = producer.add(EmailJob { to: "ada@example.com".into() }).await?;
Use this if you want the strongest "pick your stack" moment and you're OK letting in three external brand colors as accents. Trades some of the monochrome restraint for instant recognition. Good for first-time visitors; a bit louder than the rest of the page on repeat visits. The brand color is a thin 3px edge only — not a fill — to keep noise down.

Recommendation

Ship A. The frame is the affordance. Adding icons is fine but optional; the segmented control reads as a switcher even without them. Lowest noise, fits the brutalist-restrained / systems-tool direction in DESIGN.md, AA on both themes, and matches what a senior backend engineer expects from a docs site they'd take seriously. C is a fine fallback if you decide later that the landing should feel more "stack-picker" and less "config panel."
