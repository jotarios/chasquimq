  <h2 id="quickstart-title" class="chasqui-section__opener">Pick your language</h2>
  <p class="chasqui-section__lede">The engine is the same Rust binary in every package. Install, enqueue a job, run a worker.</p>

<p class="chasqui-quickstart__prereq">All three quickstarts assume Redis 8.6 running on <code>127.0.0.1:6379</code>:</p>

```bash
docker run -d --name chasquimq-redis -p 6379:6379 redis:8.6
```

<Tabs syncKey="lang">
  <TabItem label="Node.js">

**Requires Node.js 18+.** In a fresh directory, save the snippet as <code>worker.ts</code>, then:

```bash
npm init -y && npm pkg set type=module
npm install chasquimq tsx
npx tsx worker.ts
```

```ts
// worker.ts
import { Queue, Worker } from "chasquimq"

const connection = { host: "127.0.0.1", port: 6379 }
const queue = new Queue("emails", { connection })

const worker = new Worker(
  "emails",
  async (job) => {
    console.log(`[worker] sending email to ${job.data.to}`)
    return { delivered: true }
  },
  { connection, storeResults: true },
)

const job = await queue.add("welcome", { to: "ada@example.com" })
console.log(`[producer] enqueued job ${job.id}`)

await job.waitForResult({ timeoutMs: 30_000 })
console.log("🎉 your first ChasquiMQ job ran end-to-end")

await worker.close()
await queue.close()
```

  </TabItem>
  <TabItem label="Python">

**Requires Python 3.9+.** In a fresh directory, save the snippet as <code>worker.py</code>, then:

```bash
python -m venv .venv && source .venv/bin/activate
pip install chasquimq
python worker.py
```

```python
# worker.py
import asyncio
from chasquimq import Queue, Worker, Job

async def send_email(job: Job) -> dict:
    print(f"[worker] sending email to {job.data['to']}")
    return {"delivered": True}

async def main() -> None:
    queue = Queue("emails")
    worker = Worker("emails", send_email, store_results=True)
    asyncio.create_task(worker.run())

    job = await queue.add("welcome", {"to": "ada@example.com"})
    print(f"[producer] enqueued job {job.id}")

    await job.wait_for_result(timeout=30.0)
    print("🎉 your first ChasquiMQ job ran end-to-end")

    await worker.close()
    await queue.close()

asyncio.run(main())
```

  </TabItem>
  <TabItem label="Rust">

**Requires Rust 1.85+ (edition 2024).** Spin up a project, paste the snippet into `src/main.rs`, then:

```bash
cargo new chasquimq-hello && cd chasquimq-hello
cargo add chasquimq anyhow bytes
cargo add tokio --features macros,rt-multi-thread
cargo add tokio-util --features rt
cargo add serde --features derive
cargo run            # Ctrl+C to stop the consumer loop
```

```rust
// src/main.rs
use chasquimq::{Producer, Consumer, ProducerConfig, ConsumerConfig};
use serde::{Serialize, Deserialize};
use tokio_util::sync::CancellationToken;

#[derive(Clone, Serialize, Deserialize)]
struct EmailJob { to: String }

#[tokio::main]
async fn main() -> anyhow::Result<()> {
    let producer = Producer::<EmailJob>::connect(
        "redis://127.0.0.1:6379",
        ProducerConfig { queue_name: "emails".into(), ..Default::default() },
    ).await?;

    let id = producer.add(EmailJob { to: "ada@example.com".into() }).await?;
    println!("[producer] enqueued job {id}");

    let consumer = Consumer::<EmailJob>::new(
        "redis://127.0.0.1:6379",
        ConsumerConfig { queue_name: "emails".into(), ..Default::default() },
    );

    let cancel = CancellationToken::new();
    let cancel_after_first = cancel.clone();
    consumer.run(move |job| {
        let cancel = cancel_after_first.clone();
        async move {
            println!("[worker] sending email to {}", job.payload.to);
            cancel.cancel();
            Ok(bytes::Bytes::new())
        }
    }, cancel).await?;

    println!("🎉 your first ChasquiMQ job ran end-to-end");
    Ok(())
}
```

<section class="chasqui-section" aria-labelledby="arch-title">
  <h2 id="arch-title" class="chasqui-section__opener">Architecture at a glance</h2>
  <p class="chasqui-section__lede">Producers <span class="mono">XADD</span> onto a Redis Stream. Delayed jobs sit in a sorted set until a promoter moves them. Consumers <span class="mono">XREADGROUP</span>, dispatch to your handler, then <span class="mono">XACKDEL</span> in a single batched round trip. Failures retry with backoff; exhausted ones land in the DLQ.</p>
  <pre class="chasqui-arch" aria-label="ChasquiMQ data flow"><code>{`Producer ── XADD ─────────────▶ stream:emails  ──▶ XREADGROUP ──▶ Consumer
   │                                                              │
   └─ delayed: ZADD ──▶ zset:emails:z ──▶ promoter ──▶ XADD       │
                                                                  ▼
                                                              handler(job)
                                                                  │
                                                       success ◀──┴──▶ failure
                                                          │              │
                                                       XACKDEL       retry / DLQ`}</code></pre>
